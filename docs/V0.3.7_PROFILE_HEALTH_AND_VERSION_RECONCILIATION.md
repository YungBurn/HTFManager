## What changed

Profile health remains part of v0.3.7 because durable expected state and `VersionMismatch` detection are required for safe `.htfbundle` import planning.

However, **version reconciliation is no longer a v0.3.7 implementation target**.

v0.3.7 will detect and display:

```text
Expected 1.2.0
Installed 2.0.0
→ VersionMismatch
```

but it will not automatically or interactively replace an already-installed different version as part of this milestone.

This separation prevents the new portable bundle/export/import work from being mixed with downgrade/update ownership semantics.
