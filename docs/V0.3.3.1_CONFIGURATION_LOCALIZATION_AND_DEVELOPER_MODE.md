# v0.3.3.1 — Configuration Localization & Developer Mode

## Design goals

This release separates raw configuration data from presentation. HTF Manager never translates the actual persisted configuration key/value format.

```text
Raw .cfg / Loader.cfg
        |
        v
Configuration parser
        |
        +---------------------------+
        |                           |
        v                           v
Raw entry metadata          Local schema resolver
        |                           |
        +-------------+-------------+
                      v
              Configuration UI
```

## Trusted localization scope

The first schema set only contains reviewed local mappings for BepInEx core configuration and MelonLoader Loader.cfg. Third-party Mod configuration remains author-provided text unless a future reviewed schema is explicitly added for that specific Mod identity.

The schema resolver therefore never uses a generic "this came from Thunderstore" rule. Loader configuration identity is explicit and deterministic.

## Value type policy

Value type names are not localized. The original metadata type remains the source of truth. Normal mode hides this implementation detail; Developer Mode shows it exactly as parsed.

## Safety acknowledgement

The Configuration page contains a local overlay rather than creating a second Window. Navigation remains part of the main HTF Manager shell.

Acknowledgement is versioned:

```text
CurrentSafetyNoticeVersion = 1
AcknowledgedConfigSafetyVersion = <local value>
```

The overlay is visible when the acknowledged version is lower than the current notice version.

## Developer Mode boundary

Developer Mode is presentation-only. It never changes:

- Package Inspector blocking rules;
- path traversal protection;
- loader conflict protection;
- Mod ownership rules;
- game-running write locks;
- Loader ownership protection.

## Schema layout

Reviewed local mappings are Avalonia resources under:

```text
src/HTFManager.App/Localization/ConfigSchemas/
  BepInEx/zh-CN.json
  MelonLoader/zh-CN.json
```

Each schema contains section display mappings and per-entry display metadata:

```json
{
  "sections": {
    "Caching": "缓存"
  },
  "entries": {
    "Caching/EnableAssemblyCache": {
      "title": "启用程序集缓存",
      "description": "...",
      "recommendation": "建议保持启用。",
      "advanced": false,
      "restartRequired": true
    }
  }
}
```

No schema changes the source config file.
